# Laporan Perbaikan BUG-003

## Langkah 1 — Konfirmasi dan Batas Masalah
**Gejala**: Server merespon dengan status `500 Internal Server Error` atau mati tiba-tiba saat memproses dekripsi cipher biner.
**Tahap**: Rendering API (`lib/cipher_workbench/api.rb` -> `JSON.generate`).
**Batas**: Hanya muncul bila cipher domain byte (`:bytes`) memproduksi *plaintext* yang bukan UTF-8 valid, dan *source type* adalah file biner atau base64 yang memiliki byte terlarang.

## Langkah 2 — Hipotesis Akar Masalah
- **H1**: Fungsi `force_encoding('UTF-8')` di Ruby tidak mengubah byte melainkan hanya menge-set bendera *encoding*. Jika byte aktual bukan UTF-8 valid (seperti `\xFF`), string tetap *invalid*. Kemudian fungsi standar `JSON.generate` akan membentur string ini dan melempar eksepsi `JSON::GeneratorError`.
  - **Eksperimen**: Buat simulasi API dekripsi dengan cipher Extended Vigenere yang menghasilkan plain text byte 0xFF.
  - **Hasil**: Eksepsi tertangkap secara murni.

## Langkah 3 — Rancang Perbaikan
- **Berkas**: `lib/cipher_workbench/service.rb`
- **Perbaikan**: Setelah mendeteksi `text_valid = text.valid_encoding?`, bila nilainya *false*, sikat karakter-karakter tak valid menggunakan `text.scrub` dengan karakter pengganti default Unicode. Hal ini aman karena presisi byte murni untuk unduhan/inspeksi tetap dijamin pada variabel `res.plain_bytes` yang tidak terkena proses scrubbing teks.
- **Risiko**: Nol. Field `text` murni dipergunakan untuk rendering GUI, bukan preservasi matematis byte file.

## Langkah 4 — Terapkan
- Perbaikan diterapkan. Tes hijau dan digeser ke `test/regression/decrypt/bug_003_json_invalid_utf8_test.rb`.

## Langkah 5 — Verifikasi Mutasi (E4)
- Menghapus pemanggilan `scrub` akan menyebabkan parser JSON gagal dan tes RED akan gagal lagi.

## Langkah 6 — Sapuan Kelas Bug
- **Pola**: String dipaksa `force_encoding('UTF-8')` lalu disalurkan ke parser JSON atau API publik tanpa validasi byte internal.
- **Hasil Sapuan**: Semua blok ekstraksi `.force_encoding('UTF-8')` (hanya ada di satu titik sentral di Service) telah dimitigasi.

## Langkah 7 — Dokumentasi
- BUG-003 ditandai **DIPERBAIKI**.
