# Laporan Perbaikan BUG-001

## Langkah 1 — Konfirmasi dan Batas Masalah
**Gejala**: Menjalankan `test/gui_test.rb` gagal dengan pesan `ArgumentError: invalid byte sequence in US-ASCII` pada berkas `favicon.ico`.
**Tahap**: Pemindaian teks pada berkas GUI (`test_no_external_assets`).
**Batas**: Hanya terjadi bila locale/LANG environment tidak ditetapkan ke UTF-8 (sehingga `File.read` ber-fallback ke default OS yaitu US-ASCII) dan file yang dibaca merupakan file biner (seperti `.ico`).

## Langkah 2 — Hipotesis Akar Masalah
- **H1**: Regex gagal karena `content` berisi *string* ber-encoding US-ASCII namun memuat *byte* tidak lazim dari format biner.
  - **Eksperimen**: Ganti `File.read(file)` menjadi `File.read(file, mode: 'rb').encode(...)` untuk mensterilkan teks.
  - **Hasil**: Tes lolos. Akar dikonfirmasi.
- **Pelajaran Mengapa Lolos Sebelumnya**: Tes ditulis dan dijalankan secara historis di lingkungan yang `ENV['LANG']` sudah ter-set ke UTF-8, sehingga tidak *crash* langsung, atau berkas `favicon.ico` saat itu belum tersentuh tes.

## Langkah 3 — Rancang Perbaikan
- **Berkas**: `test/gui/gui_test.rb:48`
- **Perbaikan**: Menggunakan `mode: 'rb'` untuk membaca byte murni, lalu diubah ke `UTF-8` dengan metode sanitasi (`replace: ''`) untuk menghindari *ArgumentError* pada Regex `/.../i`.
- **Risiko**: Nol, karena hanya untuk keperluan tes grep.

## Langkah 4 — Terapkan
- Perbaikan telah dipasang. Tes `test/gui/gui_test.rb` terbukti HIJAU (1330 assertions, 0 failures).

## Langkah 5 — Verifikasi Mutasi (E4)
- Jika perbaikan dicabut (dikembalikan ke `File.read(file)`), *ArgumentError* langsung muncul lagi (RED).
- Mutasi dengan mengganti `.encode('UTF-8')` ke format lain yang tak valid akan ditangkap. Bukti sangat cukup.

## Langkah 6 — Sapuan Kelas Bug
- **Pola**: `File.read` ke file generik (bisa jadi biner) lalu dikenakan operasi `String`.
- **Hasil Sapuan**: Tidak ada file lain yang melakukan rekursif `File.read` tanpa mengetahui tipe isinya di production code.

## Langkah 7 — Dokumentasi
- BUG-001 ditandai **DIPERBAIKI**.
